# Scope Quest: Instructor run sheet (2 activities, ~20 min)

**You are the Chief Auditor.** Nothing scores until you press **✔ CONFIRM**. Your phone (`/host`) shows the big button (always the next step), a 🦉 wisdom card for every card (talking point, common misconception, ISO/GHG clause, and a live stat of the most common wrong basket), and **who picked what**, so you can call on people by nickname.

(The run sheet for the full 45-minute game is in `RUN_SHEET-full-version.md`.)

| Clock | Scene | What you do / say |
|---|---|---|
| **−10:00** | Before class | Open the `/host` link on your phone, enter the PIN, tap **Open projector screen** on the laptop, click once (sound), press **F** (fullscreen). Remote → Room → ♻️ **Reset game** so the room starts empty. |
| **0:00** | **Lobby** (QR + room code on screen) | "Phones out. Scan the QR or type the room code, pick a nickname. No app, no account." Wait until the counter slows down. |
| **2:00** | **Activity 1 · Sort the scopes** | Big button **▶ Start the show**, then **⏱ Start timer** (90 s). Say: "Drag each card into its basket. Ask yourself: who owns it, and where does the CO₂ come out?" The screen shows live basket counts. |
| **3:30** | Lock → reveal | **🔒 Lock answers** → **📊 Show split (card 1)** → **✔ CONFIRM**, card by card. Hot cards: **electric vans** ("same owner as the diesel vans, but the exhaust moved to the power plant → Scope 2"), **chilled water** ("Scope 2 isn't only electricity: steam, heat and cooling you buy count too"), **refrigerant** ("nothing burns, but it's still Scope 1"). If the room splits (no basket above 60%), **🎤 Debate** picks one nickname per side. Short on time? **⏩ All → summary**. |
| **8:00** | **Results summary** | The screen shows % correct for every card and the most common wrong basket. Talk about the red ones. **▶ Next activity**. |
| **9:00** | **Activity 2 · What kind of data is it?** | **⏱ Start timer** (120 s). Say: "Same game, new baskets. For each piece of data ask: *who measured it, and where?*" |
| **11:00** | Lock → reveal | Card by card as before. Key lines: **gas invoices** "That's primary data, and more precisely **site-specific**: the meter is ours, inside our boundary. All site-specific data are primary (ISO 14064-1, 3.2.3). Primary scores half." **Courier's fuel logs** "Measured, so primary, but collected outside our boundary, so not site-specific." **DESNZ factor** "This is the conversion step. It comes from a published database, so it's secondary (3.2.4)." **IPCC default leak rate** "Our fridges, but nobody measured them: a default from literature is secondary (Annex C.5)." |
| **17:00** | **Results summary** | "Most inventories mix the two: our litres (primary) × a database factor (secondary)." **▶ Next activity**. |
| **18:00** | **Finale** | Podium (confetti) → top 3 individuals → read the **3 takeaways**. "Screenshot your card." |
| **20:00** | After | Room tab → **⬇️ Export CSV**. Stats tab = hardest cards first. |

**Debate moment script (any card):** "🎤 *Name A*, you said X. Convince *Name B*." (30 s) → "*Name B*, your reply?" (30 s) → "Let's see what the standard says…" → **Confirm**.

**If wifi dies:** toggle **Screen-only** on the remote (phones go idle, the screen asks for a show of hands).
